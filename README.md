# kamry
=======
Welcome, this is the code base for my Kamry with a K project.
I am gutting a 1996 Camry, swapping a K24 into it, installing a RusEFI standalone ECU, and making my own dash and custom body control modules for the few functions that remain.

Currently the plan includes:

Dash:
Pi 4 with waveshare can bus hat, receiving ecu and bcm signals
SFML for graphics
7" display

Front body control module:
Control front lights
Receive signals from factory column/brake pedal
Custom panel for window/lock/mirror controls

Rear body control module:
Control rear lights
fuel pump sender


front doors:
control window/lock/mirrors
